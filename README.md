## 🎯 2주차 수업 운영 전략 (초보자 성공 보장)

### 1. 백지 코딩 금지 → "오픈소스 조립 및 커스텀"
* 학생들이 메모장에서 `<html>`부터 타이핑하는 방식 대신, 완성도 높은 `01_학생_실습용_템플릿`을 제공합니다.
* AI에게 **"내 이름과 설계 주제로 바꿔줘"**, **"색상을 오렌지로 바꿔줘"**라고 지시하는 **바이브 코딩(Vibe Coding)** 방식을 훈련합니다.

### 2. 챗봇 오픈소스 위젯의 듀얼 트랙 (Dual-Track) 설계
* **옵션 B (기본 룰베이스 모드 - 수업 성공률 100%)**:
  * 40~50명의 학생이 일제히 API 키를 발급받다가 겪는 계정/인증/카드 등록 오류를 원천 차단합니다.
  * API 키 없이도 추천 질문 칩(채광 원리, 캔틸레버 구조, 재료, 연락처)을 누르면 즉시 고품질 답변이 출력됩니다.
* **옵션 A (Google Gemini 1.5 Flash 연동 모드 - 심화 과제)**:
  * 챗봇 상단 ⚙️ 설정 아이콘에서 학생 개인 키를 입력하면 브라우저에 임시 저장되어 실제 실시간 AI 대화가 동작합니다.
  * 깃허브 공개 배포 시 API 키가 코드 파일에 노출되지 않도록 `localStorage` 기반으로 안전하게 설계되었습니다.
