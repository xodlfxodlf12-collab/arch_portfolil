ARCHITECTURE VIBE-CODING CURRICULUM

건축학과 학생을 위한 바이브 코딩 4단계 로드맵

복잡한 코딩 문법 대신, AI와 대화하며 나만의 인터랙티브 건축 포트폴리오를 기획·제작·배포하는 실습 커리큘럼입니다.

1 11주차: 프론트엔드 제작 & AI 도슨트 연결
수업 시간: 2~3시간 소요

🏛️ 나만의 건축 포트폴리오 웹사이트 기초 구축

학생이 지난 학기에 작업했던 패널, 렌더샷, 다이어그램을 웹페이지에 담고, 방문자에게 설계 의도를 말해주는 AI 도슨트(Gemini API)를 장착합니다.

🎯 학생 전달 핵심 내용

• 웹사이트의 3대 뼈대(HTML 구조, CSS 스타일, JS 동작)의 역할을 감각적으로 이해하기
• PDF와 달리 반응형(PC/모바일)으로 작동하는 웹 갤러리의 장점

💬 AI와 협업하는 방법 (바이브 코딩)

• "코드 다 짜줘" 대신 "내 설계 의도(보이드, 사괴석 담장)에 어울리는 차분한 다크모드 테마로 만들어줘"처럼 건축 어휘로 AI에게 지시하기

🤖 무료 AI API 연동 실습

• Google AI Studio에서 무료 Gemini API Key 발급받기
• 방문자가 질문하면 내 프로젝트를 대변해 답해주는 큐레이터 챗봇 연결

📌 학생들에게 제공할 AI 지시문 템플릿 
"나는 건축학과 4학년 김진우야. 지난 학기에 삼청동에 설계한 '비움의 미술관' 프로젝트가 있어.
- 대지: 서울시 종로구 삼청동, 연면적 2,450㎡
- 주요 컨셉: 사괴석 담장과 빛의 우물(천창 탑라이트)을 통한 보이드 공간
이 내용을 바탕으로 웹사이트에서 카드 클릭 시 열리는 예쁜 모달 팝업 코드를 작성해줘.
그리고 방문자가 천창 채광에 대해 물어보면 설명해 주는 AI 답변 예시도 만들어줘."
✅ 11주차 달성 체크리스트
내 스튜디오 작품 사진 2장 이상 갤러리에 교체하기
프로젝트 카드 클릭 시 상세 모달 창 정상 동작 확인
AI 챗봇에 "미술관 채광 원리 알려줘" 질문 후 답변 받아보기
2 12주차: 무료 웹 호스팅 & 모바일 링크 완성
수업 시간: 1.5~2시간 소요

🌐 내 포트폴리오를 전 세계에 무료 배포하기 (Vercel / GitHub)

내 컴퓨터(Localhost)에서만 보이던 웹사이트를 클릭 몇 번으로 실제 인터넷 주소(URL)로 배포하여 스마트폰으로 접속해봅니다.

🎯 학생 전달 핵심 내용

• 로컬 실행(내 컴퓨터)과 웹 배포(서버 호스팅)의 차이점 이해
• Vercel / GitHub Pages를 이용한 완전 무료 영구 호스팅

📱 모바일 반응형(Responsive) 점검

• 크롬 개발자 도구(F12) 모바일 보기 모드로 스마트폰 화면에서 레이아웃이 깨지지 않는지 AI에게 수정 요청하기

🔒 보안 및 환경변수 주의점

• 무료 API 키가 깃허브 공개 저장소에 그대로 노출되지 않도록 하는 기본 보안 수칙 교육

📌 학생들에게 제공할 AI 지시문 템플릿 
"스마트폰 화면에서 확인해보니까 3D 뷰어와 프로젝트 카드가 좌우로 삐져나와.
아이폰이나 갤럭시 세로 모드(화면 너비 400px 이하)에서도 깔끔하게 1열로 정렬되도록 style.css의 미디어 쿼리를 보완해줘."
✅ 12주차 달성 체크리스트
GitHub 리포지토리 생성 후 파일 푸시 완료
Vercel 무료 배포로 개인 전용 URL (예: jinwoo-arch.vercel.app) 획득
스마트폰으로 내 링크 접속해 모바일 최적화 확인
3 13주차: MCP 블렌더 3D 모델링 → 웹 뷰어 탑재
수업 시간: 2~3시간 소요

🧊 AI로 3D 매스 모델링 자동화하고 웹에 마우스로 돌려보기

최신 기술인 MCP(Model Context Protocol)를 이용해 AI에게 자연어로 블렌더(Blender) 3D 조작을 지시하고, 완성된 모델을 웹사이트 뷰어에 연동합니다.

🎯 학생 전달 핵심 내용

• MCP 개념: AI가 텍스트만 출력하는 것을 넘어 내 컴퓨터의 소프트웨어(Blender)를 직접 조작하는 에이전트 워크플로우 경험

📐 3D 매스 생성 및 재질 부여

• 파라메트릭 매스, 포디움 분절, 캔틸레버 형태 생성 지시
• 웹 3D 표준 규격인 `.gltf` / `.glb` 파일 형식 이해

🕹️ Three.js 웹 뷰어 교체

• 11주차 웹사이트의 3D 캔버스 영역에 내가 익스포트한 3D 모델을 넣어 마우스 드래그로 돌려보기

📌 학생들에게 제공할 AI 지시문 템플릿 
"Blender MCP를 사용해서 현대적인 미술관 콘셉트의 매스를 생성해줘:
1. 바닥 면적 20x15m, 높이 4m의 하부 포디움
2. 2층은 45도 회전된 12x12m 큐브 매스 (2m 캔틸레버 돌출)
3. 외벽은 무광 콘크리트 재질, 중앙부는 유리 커튼월 보이드로 지정해줘.
완성되면 WebGL 뷰어용 GLTF 포맷으로 저장하는 스크립트를 실행해줘."
✅ 13주차 달성 체크리스트
블렌더에서 자연어 프롬프트로 3D 오브젝트 생성 성공
glTF 파일 추출 후 웹 프로젝트 폴더로 복사
웹 브라우저에서 마우스로 내 3D 모델 360도 회전 검토
