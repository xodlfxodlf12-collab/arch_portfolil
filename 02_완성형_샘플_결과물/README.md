# 🏛️ 02_완성형_샘플_결과물 (ARCHI-FOLIO Master Showcase)

본 폴더는 **건축 인터랙티브 AI 포트폴리오의 최종 완성본**입니다.  
2주차 수업 시작 시 학생들에게 *"오늘 우리가 AI와 함께 완성할 최종 목표 결과물"*로서 프로젝터 화면에 시연하거나 데모로 제공하는 기준 모델입니다.

---

## 🌟 탑재된 핵심 기능

1. **상용급 아키텍처 다크 테마 디자인**
   - 도면 감성의 블루프린트 그리드 배경, 반응형 글래스모피즘 UI
   - 프로젝트 갤러리(문화/도시/주거) 및 상세 모달 팝업

2. **Three.js WebGL 인터랙티브 3D 매스 뷰어**
   - 마우스 드래그 360도 회전, 와이어프레임/클레이 모드 토글
   - 부재별(기단부, 캔틸레버, 유리 보이드, 캐노피) 공간 조닝 분석 및 발광 하이라이트
   - `models/building.glb` 자동 로드 및 화면에서 즉석 `.glb/.gltf` 업로드 지원

3. **관점별 30초 핵심 브리핑 (Audience-Tailored Briefing)**
   - 심사위원/교수님 평가 시각에 맞춘 4대 관점(조형, 동선, 구조, 컴퓨테이셔널 툴체인) 탭 전환

4. **🤖 플로팅 AI 도슨트 챗봇 위젯 (Dual-Track 하이브리드)**
   - **기본 모드 (옵션 B: 룰베이스)**: API 키 없이도 추천 질문 칩(채광 원리, 캔틸레버 구조, 친환경 재료, 연락처) 클릭 시 즉각 전문 해설 출력
   - **실시간 AI 모드 (옵션 A: Gemini 1.5 Flash)**: 상단 ⚙️ 설정에서 Google AI Studio API 키를 입력하면 실제 LLM과 실시간 자유 대화 지원
