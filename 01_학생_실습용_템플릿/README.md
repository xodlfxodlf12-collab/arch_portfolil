# 🏛️ [2주차 실습] AI와 함께 만드는 나만의 건축 포트폴리오 웹사이트

> **수업 목표:** 복잡한 코딩 문법을 외우지 않고, 완성형 템플릿을 AI(Antigravity / ChatGPT / Claude)에게 요청하여 **단 40분 만에 나만의 인터랙티브 웹 포트폴리오와 챗봇**으로 리모델링합니다.

---

## ⚡ 1분 만에 시작하기 (로컬 실행)

1. 폴더 안의 **`index.html`** 파일을 더블 클릭합니다.
2. 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 사이트가 즉시 열립니다.
3. 마우스로 3D 건물을 360도 회전해보고, 우측 하단의 **🏛️ 플로팅 챗봇 아이콘**을 눌러 추천 질문을 클릭해 보세요.

---

## 🛠️ 오늘 실습 미션 3가지 (바이브 코딩)

스스로 코드를 다 치지 마세요! AI에게 아래 **[복사해서 쓸 프롬프트]**를 전달하여 수정하세요.

### 미션 1. 내 이름과 소개 문구로 리모델링하기
* **수정 대상 파일:** `index.html` (Hero 섹션), `script.js` (`projectsData`)
* **AI에게 던질 프롬프트 예시:**
  > "이 웹사이트의 `index.html`에서 작성자 이름을 '건축학과 2학년 [내이름]'으로 바꾸고, 메인 소개 문구를 [내가 추구하는 건축 스타일, 예: 자연과 조화되는 친환경 목구조 공간]으로 수정해줘."

### 미션 2. 나만의 테마 컬러(퍼스널 컬러) 입히기
* **수정 대상 파일:** `style.css` 상단 (`--accent`)
* **AI에게 던질 프롬프트 예시:**
  > "`style.css`의 메인 포인트 컬러(`--accent`)를 현재 민트색에서 내 퍼스널 컬러인 '[예: 따뜻한 테라코타 오렌지색 #f97316]'으로 사이트 전체 분위기에 맞게 변경해줘."

### 미션 3. 나만의 AI 도슨트 챗봇 만들기 (추천 질문 & 답변)
* **수정 대상 파일:** `index.html` (추천 칩 버튼), `script.js` (`scenarioResponses`)
* **AI에게 던질 프롬프트 예시:**
  > "`script.js`의 `scenarioResponses` 데이터베이스에 내 프로젝트 관련 질문과 답변을 추가하고 싶어.
  > 1) 질문 키워드: '주민센터', '설계의도' -> 답변: '[내 설계 설명]'
  > 2) 질문 키워드: '인스타', '연락처' -> 답변: '[내 인스타그램 및 이메일]'
  > 이렇게 매칭되도록 코드를 수정해주고, `index.html`의 챗봇 추천 질문 버튼도 이에 맞게 바꿔줘."

## 💡 챗봇 모드 안내 (옵션 B vs 옵션 A)

* **기본 모드 (옵션 B: 시나리오 룰베이스)**:
  * API 키 발급 없이도 추천 질문 버튼을 누르면 100% 즉시 답변이 나오는 안전한 모드입니다.
  * 네트워크 장애나 API 비용, 키 유출 걱정 없이 마음껏 수정하고 시연할 수 있습니다.
* **실시간 AI 모드 (옵션 A: Google Gemini 1.5 Flash)**:
  * 챗봇 대화창 우측 상단의 **⚙️ 설정 아이콘**을 누르면 본인의 Google AI Studio 무료 API Key를 입력하여 실제 실시간 생성형 AI로 전환할 수 있습니다. (키는 브라우저 로컬에만 임시 저장됩니다)
