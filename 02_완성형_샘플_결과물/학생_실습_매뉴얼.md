## 1. 준비 운동: 내 컴퓨터에서 바로 열어보기

1. 압축을 푼 `01_학생_실습용_템플릿` 폴더로 이동합니다.
2. **`index.html`** 파일을 마우스로 **더블 클릭**합니다.
3. Chrome(크롬) 또는 Edge(엣지) 브라우저가 열리며 웹사이트가 즉시 나타납니다.
4. **체크 포인트:**
   - 마우스 왼쪽 드래그로 화면 중앙의 3D 건물을 360도 돌려보세요.
   - 우측 하단의 **🏛️ 동그란 챗봇 버튼**을 눌러 추천 질문 버튼을 눌러보세요.

## 2. 폴더 지도: 파일들이 하는 일 한눈에 보기

복잡해 보이지만 우리가 수정할 핵심 파일은 딱 3개입니다:

| 파일명 | 역할 | 비유 |
| :--- | :--- | :--- |
| **`index.html`** | 웹사이트의 뼈대와 글자 내용 | 건축물의 **골조와 벽돌** |
| **`style.css`** | 색상, 폰트, 여백, 반투명 효과 | 건축물의 **외장재와 인테리어** |
| **`script.js`** | 3D 뷰어 회전, 팝업창, 챗봇 대화 로직 | 건물의 **엘리베이터와 조명 설비** |
| **`models/`** | 본인의 3D 파일(`.glb`)을 넣는 곳 | 1층 로비의 **모형 전시 공간** |

> 💡 **핵심 원칙:** 코드를 직접 타이핑해서 고치려 하지 마세요! AI에게 *"어떤 파일의 어디를 이렇게 바꿔줘"*라고 말하는 것이 **바이브 코딩(Vibe Coding)**입니다.

## 3. 실습 1단계: 내 프로필과 설계 철학 입히기

웹사이트 맨 위(Hero 섹션)와 맨 아래(Footer)에 내 이름과 설계 지향점을 넣습니다.

1. **`index.html`** 파일을 VS Code 또는 텍스트 에디터로 엽니다.
2. `<!-- ✏️ [학생 실습 1-1] -->` 및 `<!-- ✏️ [학생 실습 1-2] -->` 주석을 찾습니다.
3. 아래 항목을 내 정보로 바꿉니다:
   * **로고:** `ARCHIFOLIO` 대신 본인 이니셜 (예: `JIN.STUDIO`)
   * **슬로건:** 내가 추구하는 공간 철학 (예: *"자연과 사람을 잇는 지속가능한 목구조"*)
   * **자기소개:** 학년, 이름, 관심 설계 분야
   * **하단 연락처(Footer):** 이메일 주소 및 인스타그램 아이디

## 4. 실습 2단계: 나만의 테마 컬러(퍼스널 컬러) 바꾸기

현재 민트색(`--accent: #5eead4`)인 포인트 컬러를 내 작품 스타일에 맞는 색으로 한 번에 바꿀 수 있습니다.

1. **`style.css`** 파일을 엽니다.
2. 맨 첫 줄의 `/* ✏️ [학생 실습 2] */` 바로 아래를 봅니다:
   ```css
   :root {
       --accent: #5eead4; /* 👈 이 색상 코드를 원하는 색으로 변경! */
   }
   ```
3. **추천 건축 컬러 팔레트:**
   * 🌿 **친환경 / 조경 / 목구조:** 포레스트 그린 `#10b981`
   * 🧱 **코르텐강 / 적벽돌 / 따뜻한 공간:** 테라코타 오렌지 `#f97316`
   * 🏙️ **하이테크 / 도시재생 / 스마트 시티:** 일렉트릭 블루 `#38bdf8`
   * 🎨 **문화예술 / 전시공간:** 모던 바이올렛 `#a855f7`
4. 저장 후 브라우저에서 **`F5`(새로고침)**를 누르면 버튼, 테두리, 발광 효과가 모두 새 색상으로 바뀝니다!

## 5. 실습 3단계: 내 설계 작품(스튜디오 과제) 등록하기

홈페이지 중간의 **Selected Works 갤러리 카드**와 **상세 모달 창**에 내 프로젝트를 넣습니다.

1. **`script.js`** 파일을 엽니다.
2. 상단의 `const projectsData = [ ... ];` 배열을 찾습니다.
3. 1번 프로젝트의 정보를 지난 학기에 진행했던 내 과제 정보로 교체합니다:
   ```javascript
   {
       id: 1,
       title: "숲을 품은 마을 도서관",             // 작품 제목
       category: "cultural",                   // cultural(문화), urban(도시), residential(주거)
       year: "2025.Spring (3학년 1학기)",
       location: "서울시 마포구 연남동 일대",
       area: "연면적 1,820 ㎡ / 지상 3층",
       structure: "중목구조(Glulam) + 노출콘크리트",
       concept: "주택가 골목길의 보행 동선을 대지 내부로 자연스럽게 끌어들여...",
       images: [
           "내 이미지 URL 또는 로컬 경로"
       ]
   }
   ```

> 🌟 **놀라운 비밀:** 여기서 `concept(설계 개념)`에 적은 내용은 **AI 도슨트 챗봇에게 자동으로 학습(주입)**됩니다! 관리자 페이지에서 따로 등록할 필요가 없습니다.

## 6. 실습 4단계: 나만의 AI 도슨트 챗봇 완성하기

방문자가 내 사이트에 들어왔을 때, 나 대신 내 설계를 브리핑해 주는 **AI 도슨트**를 완성합니다.

### ① 기본 모드 (옵션 B: 시나리오 룰베이스) - *수업 필수!*
* API 키가 없어도 질문 버튼을 누르면 100% 즉시 답변이 나오는 안전한 모드입니다.
* **수정 방법:** `script.js`의 `scenarioResponses`에서 키워드와 답변을 내 과제 내용으로 바꿉니다.
  ```javascript
  {
      keywords: ["채광", "빛", "창", "자연광"],
      answer: "제 도서관 프로젝트는 북측 고창을 통해 눈부심 없는 부드러운 산란광을 열람실 깊숙이 전달하도록 설계했습니다."
  }
  ```
* `index.html` 323번 줄의 추천 버튼 칩 이름도 내 질문으로 바꿔줍니다.

### ② 실시간 AI 모드 (옵션 A: Google Gemini API 연동) - *도전 과제!*
1. [Google AI Studio](https://aistudio.google.com/)에 구글 계정으로 로그인합니다.
2. **[Get API Key]** 버튼을 눌러 무료 API 키(`AIzaSy...`)를 발급받아 복사합니다.
3. 내 웹사이트 챗봇 창 우측 상단의 **⚙️ 설정 아이콘**을 클릭합니다.
4. 복사한 키를 붙여넣고 **[Gemini 연동 저장]**을 누릅니다.
5. 이제 챗봇은 최신 **Gemini 3.5 Lite / Flash-Lite** 모델과 실시간 연결되어, 3단계에서 입력한 내 프로젝트 데이터를 바탕으로 방문자와 자유롭게 심층 대화를 나눕니다!

## 7. 실습 5단계: 내 3D 모델(.glb) 띄워보기 (선택)

내가 모델링한 건물을 웹 브라우저에서 3D로 직접 띄워볼 수 있습니다.

1. Rhino, SketchUp, Blender에서 내 건물을 **`.glb`** 또는 **`.gltf`** 형식으로 내보냅니다.
   *(💡 팁: 빠른 로딩을 위해 텍스처를 단순화하고 용량을 10MB~20MB 이하로 권장)*
2. 파일 이름을 **`building.glb`**로 변경합니다.
3. `models` 폴더 안에 넣고 웹페이지를 새로고침(F5)하면, 기본 매스 대신 **내 3D 건물이 뷰어에 자동으로 렌더링**됩니다!
4. *(간이 테스트: 3D 뷰어 화면의 `📁 내 3D 모델 업로드` 버튼을 눌러 파일을 바로 선택해도 됩니다)*

## 8. 치트키: AI에게 복사해서 던지는 프롬프트 5선

Antigravity 또는 ChatGPT에 아래 문장을 그대로 복사해서 붙여넣으세요:

### 🎯 프롬프트 1 (프로필 리모델링)
> "이 웹사이트의 `index.html`에서 작성자 이름을 '건축학과 3학년 김민서'로 바꾸고, 슬로건을 '빛과 그림자가 만드는 침묵의 공간'으로 변경해줘. 그리고 소개글도 이에 어울리는 감성적인 건축 디자이너 문구로 다듬어줘."

### 🎯 프롬프트 2 (테마 컬러 변경)
> "`style.css`에서 현재 민트색인 `--accent` 색상을 따뜻한 테라코타 벽돌 느낌의 오렌지색(`#f97316`)으로 바꾸고, 이에 어울리게 뱃지와 그림자 톤도 자연스럽게 맞춰줘."

### 🎯 프롬프트 3 (내 프로젝트 데이터 입력)
> "내가 지난 학기에 설계한 주민센터 프로젝트 내용이야:
> - 이름: 어반 테라스 주민커뮤니티센터
> - 위치: 서울 마포구, 연면적 3,200㎡, 철골철근콘크리트 구조
> - 컨셉: 계단식 야외 테라스를 통해 주민들이 골목길을 걷듯 옥상 정원까지 오르내리는 열린 공공청사
> 이 내용을 `script.js`의 `projectsData` 1번 형식에 맞게 자바스크립트 코드로 작성해줘."

### 🎯 프롬프트 4 (챗봇 질문/답변 시나리오 추가)
> "`script.js`의 `scenarioResponses` 배열에 내 프로젝트 관련 질문 3개(야외 테라스 동선, 구조적 특징, 연락처)를 추가하고, `index.html`의 챗봇 추천 버튼 칩도 이에 맞춰 교체해줘."

### 🎯 프롬프트 5 (코드 에러 해결 요청)
> "방금 코드를 고쳤는데 웹사이트에서 3D 뷰어가 안 떠. 내 `script.js` 코드에서 문법 오류(쉼표 누락이나 괄호 닫기 등)가 있는지 검사하고 수정된 전체 코드를 알려줘."

## 9. 자주 묻는 질문 (FAQ)

**Q1. `index.html`을 수정했는데 브라우저 화면이 안 바뀌어요!**  
👉 브라우저에 예전 캐시가 남아있을 수 있습니다. 키보드의 **`Ctrl + Shift + R` (강력 새로고침)**을 누르세요.

**Q2. AI API 키를 넣었는데 "지원되지 않는 모델" 에러가 떠요.**  
👉 최신 코드는 **Gemini 3.5 Lite / Flash-Lite** 모델을 자동으로 탐색하도록 업그레이드되어 있습니다. 상단 ⚙️ 설정에서 [룰베이스 모드로 초기화]를 누르셨다가 키를 다시 저장해 보세요.

**Q3. 깃허브(GitHub Pages)에 올릴 때 API 키가 남들에게 보이지 않나요?**  
👉 안전합니다! 본 템플릿은 API 키를 코드 파일에 하드코딩하지 않고, 브라우저 로컬 저장소(`localStorage`)에만 임시 보관하므로 깃허브에 코드를 올려도 키가 외부에 유출되지 않습니다.
